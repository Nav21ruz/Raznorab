# Лендинг «Штукатурка и шпаклевка»

Одностраничный сайт-визитка для услуги штукатурных и шпаклевочных работ.
Независимый проект (React + TypeScript + Vite + Tailwind CSS), не связанный
с приложением `Raznorab` из корня репозитория.

## Запуск

```bash
cd plastering-landing
npm install
npm run dev       # локальная разработка
npm run build     # продакшн-сборка в dist/
npm run lint
```

## Что нужно заменить перед публикацией

Все реальные данные вынесены в один файл — `src/data/content.ts`:

- `business` — название компании, город, телефон, WhatsApp, Telegram, email,
  опыт работы, число объектов, срок гарантии.
- `services` — список услуг (карточки в разделе «Услуги»).
- `prices` — таблица цен.
- `processSteps`, `advantages`, `reviews` — тексты соответствующих разделов.
- `portfolioItems` — примеры объектов. У каждого можно указать `beforeSrc` и
  `afterSrc` (путь к файлу в `public/`, например `/portfolio/1-before.jpg`) —
  как только они появятся, плейсхолдер-заглушка с иконкой камеры автоматически
  заменится на фото.

Форма в разделе «Контакты» открывает WhatsApp с заполненным сообщением
(`https://wa.me/<номер>`) — бэкенд не требуется. Номер берётся из
`business.whatsappNumber`.

## Деплой

Сборка — статические файлы в `dist/`, подходят для любого статического
хостинга (GitHub Pages, Netlify, Vercel и т.п.). Обратите внимание на `base`
в `vite.config.ts` — при деплое в корень домена измените его на `/`.
