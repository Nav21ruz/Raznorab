СТРОЙБИРЖА — свой сервер в Яндекс.Облаке (данные хранятся в России)
====================================================================

ВАЖНО ПРО ЭТУ ИНСТРУКЦИЮ: интерфейс Яндекс.Облака время от времени
меняется, и точные названия кнопок могут немного отличаться от описанных
здесь. Если что-то не находится или выглядит иначе — просто опишите мне,
что видите на экране, и я подскажу, куда нажать. Эту настройку лучше
делать вместе, по шагам, а не в одиночку — она сложнее, чем заливка
архива на обычный хостинг.

Что в итоге получится: сайт остаётся там же (на вашем домене), но вместо
Supabase (зарубежный сервис) все данные — регистрации, заказы, чат —
будут храниться на серверах Яндекс.Облака в России.

Понадобится: аккаунт в Яндекс.Облаке с привязанной банковской картой
(у Яндекса есть бесплатные пробные деньги на старте, но карта всё равно
нужна для подтверждения). Итоговая стоимость при небольшом числе
пользователей — обычно от нескольких сотен рублей в месяц.


ШАГ 1. База данных
-------------------
1. Зайдите на console.yandex.cloud, войдите или зарегистрируйтесь.
2. Создайте платёжный аккаунт (Яндекс попросит сам, при первом входе).
3. Найдите раздел "Managed Service for PostgreSQL" (может называться
   «База данных» или «PostgreSQL» в поиске по сервисам) и создайте кластер:
   - выберите самую дешёвую/минимальную конфигурацию — для начала этого
     достаточно с запасом;
   - при создании попросят задать имя базы данных и имя/пароль пользователя —
     запишите их, они понадобятся дальше;
   - в сетевых настройках разрешите доступ из интернета (публичный IP) —
     иначе сервер не сможет подключиться.
4. Дождитесь, пока кластер перейдёт в статус "Alive"/"Работает" (обычно
   несколько минут).
5. Найдите в карточке кластера строку подключения (host, порт — обычно
   6432, имя базы). Порт 6432 — это порт со встроенным пулом соединений,
   его и используем.


ШАГ 2. Загрузить структуру базы
---------------------------------
В карточке кластера должен быть раздел вроде "Query"/"SQL-запросы" —
через него можно выполнять SQL прямо в браузере. Если такого раздела нет —
подойдёт бесплатная программа DBeaver (dbeaver.io) — установите, подключитесь
данными из шага 1.

Выполните ПО ОЧЕРЕДИ содержимое следующих файлов (именно в этом порядке —
каждый следующий зависит от предыдущего). Файлы лежат в архиве с кодом,
который у вас уже есть, в папках server/sql и supabase:

    1) server/sql/000_auth_compat.sql
    2) supabase/marketplace_schema.sql
    3) supabase/moderation_schema.sql
    4) server/sql/001_auth_credentials.sql
    5) supabase/performance_schema.sql
    6) supabase/reviews_schema.sql
    7) server/sql/003_yandex_id.sql
    8) server/sql/002_grants.sql

Откройте каждый файл текстовым редактором, скопируйте содержимое целиком,
вставьте в окно SQL-запросов и выполните. Если где-то будет ошибка —
пришлите мне текст ошибки, разберёмся.

Затем создайте ВТОРОГО пользователя базы данных (в том же разделе, где
создавали первого, в карточке кластера — "Пользователи" → добавить).
Назовите его, например, raznorab_app, придумайте пароль. После создания
выполните ещё одну команду в том же SQL-окне (замените raznorab_app на
то имя, которое вы дали):

    grant authenticated to raznorab_app;

Это тот самый "обычный" пользователь, от имени которого сайт будет делать
все повседневные запросы — без особых прав, только то, что разрешают
правила безопасности в самой базе.


ШАГ 3. Хранилище для фотографий
----------------------------------
1. Найдите раздел "Object Storage".
2. Создайте бакет (контейнер для файлов) — например, raznorab-photos.
   Имя должно быть уникальным во всём Яндекс.Облаке, если занято —
   добавьте что-то к названию. Доступ на чтение — "Публичный" (иначе
   фото не откроются в браузере).
3. Найдите раздел "Сервисные аккаунты", создайте новый, дайте ему роль
   storage.editor на этот бакет (или на всё Object Storage).
4. У этого сервисного аккаунта создайте "Статический ключ доступа" —
   вам покажут Key ID и Secret Key. Секретный ключ показывается только
   один раз — сразу сохраните оба значения, они понадобятся на шаге 5.


ШАГ 4. Сам сервер (Cloud Function)
-------------------------------------
Эта часть уже подготовлена в архиве с кодом, папка server/. Дальше два
варианта — выберите тот, который вам удобнее:

  А) Отправьте мне доступ (или просто скажите "начинай"), и я подготовлю
     архив для загрузки и распишу оставшиеся клики по актуальному на
     сегодня интерфейсу Яндекс.Облака — это самая техническая часть,
     проще пройти её вместе, чем по бумажке.

  Б) Если хотите сами: в разделе "Cloud Functions" создайте функцию,
     среда выполнения — Node.js (последняя доступная версия), точка
     входа — src/yandex-handler.handler. Загружаете архив (в папке
     server/ выполнить: npm install --omit=dev, затем упаковать всё
     содержимое папки в zip, КРОМЕ файла .env). В настройках функции,
     в переменных окружения, впишите все значения из файла
     server/.env.example — с реальными данными из шагов 1-3. После
     сохранения включите публичный вызов функции (invoke rights → allUsers)
     и скопируйте её адрес (обычно вида
     https://functions.yandexcloud.net/<какой-то-код>) — это и есть
     API_URL для следующего шага.


ШАГ 5. Подключить сайт к серверу
-----------------------------------
На хостинге (там же, где лежит сайт, например reg.ru) откройте файл
config.js и впишите адрес из шага 4:

    window.__APP_CONFIG__ = {
      API_URL: 'https://functions.yandexcloud.net/ваш-адрес',
      YANDEX_CLIENT_ID: '',
      SUPABASE_URL: '',
      SUPABASE_ANON_KEY: '',
    }

(Поля SUPABASE_* трогать не нужно — они для отдельного инструмента
"Журнал объекта", который остаётся как был. YANDEX_CLIENT_ID заполняется
на следующем, необязательном шаге.)

Обновите страницу сайта — надпись про демо-режим должна исчезнуть.


ШАГ 5.5 (НЕОБЯЗАТЕЛЬНО). Вход через Яндекс
-----------------------------------------------
Добавляет на экран входа кнопку "Войти через Яндекс" — не обязательно,
сайт и без этого шага полноценно работает через email и пароль.

1. Зайдите на oauth.yandex.ru, войдите под своим Яндекс-аккаунтом.
2. "Создать приложение" (или "Зарегистрировать новое приложение").
3. Платформы — отметьте "Веб-сервисы".
4. Redirect URI (Callback URI) — впишите ТОЧНО:
       https://ваш-домен/auth/yandex/callback
   (например https://dumaev.ru/auth/yandex/callback) — если адрес не
   совпадёт с этим один-в-один, вход будет выдавать ошибку.
5. В доступе (Данные) отметьте хотя бы "Доступ к email адресу",
   "Доступ к имени, фамилии и полу" (названия пунктов могут немного
   отличаться).
6. Сохраните — покажут Client ID и Client Secret.
7. Client ID впишите в config.js (шаг 5, поле YANDEX_CLIENT_ID) —
   это не секрет.
8. Client ID и Client Secret ВМЕСТЕ впишите в переменные окружения
   сервера (YANDEX_CLIENT_ID, YANDEX_CLIENT_SECRET — там же, где
   остальные переменные из шага 4) — Client Secret не должен попасть
   на сайт, только в настройки сервера.

После этого на экране входа появится кнопка "Войти через Яндекс".


ШАГ 6. Стать администратором
--------------------------------
Зарегистрируйтесь на сайте как обычный пользователь. В SQL-окне (там же,
где выполняли файлы на шаге 2) выполните:

    select id, first_name from profiles;

Найдите свою строку, скопируйте id, выполните:

    insert into admins (profile_id) values ('сюда-ваш-id');

После этого на сайте появится раздел /admin.
